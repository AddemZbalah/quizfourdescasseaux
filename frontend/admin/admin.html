Guide Complet du Backoffice

Ce panneau explique l'ensemble des fonctionnalités disponibles pour créer, modifier et organiser le quiz.

Vue d'ensemble

Le backoffice est organisé en 2 zones:

  • Zone gauche: création rapide d'une nouvelle question.
  • Zone droite: liste des questions existantes et actions d'édition.

Schéma d'utilisation recommandé

  1. Renseigner l'intitulé de la question.
  2. Ajouter un indice optionnel (pour aider les joueurs).
  3. Choisir le type de question (QCM, Texte libre, Images).
  4. Ajouter les réponses et cocher les bonnes réponses.
  5. Enregistrer la question.
  6. Vérifier dans la liste, puis ajuster l'ordre si nécessaire.

Créer une question

  • Intitulé de la question: texte affiché aux joueurs.
  • Indice (optionnel): aide affichée pendant le quiz.
  • Type de question: QCM = choix multiples, Texte libre = saisie joueur avec mots clés, Images = question orientée visuel.

Gérer les réponses

  • + Ajouter une réponse: ajoute une ligne de réponse.
  • Case Correct ?: indique si la réponse est valide.
  • ✕ rouge: supprime la ligne de réponse en cours.

Enregistrement et retours

  • Le bouton Enregistrer la question envoie les données au backend.
  • Des messages de succès/erreur s'affichent sous le formulaire.
  • Après succès: le formulaire est réinitialisé et la liste est rechargée.

Liste des questions

  • Type | ID: métadonnées techniques de la question.
  • Indice: affiché directement avec 2 actions dédiées.
  • Modifier l'indice: met à jour l'indice sans toucher au reste.
  • Supprimer l'indice: retire l'indice pour cette question.

Organisation et maintenance

  • ↑ / ↓: change l'ordre d'apparition des questions.
  • Supprimer (question): retire la question et ses réponses associées.
  • Supprimer (réponse): retire seulement une réponse dans la liste.
  • + Ajouter une réponse (dans la liste): ajout rapide sans revenir au formulaire.

Bonnes pratiques

  • Écrire des intitulés courts et clairs.
  • Éviter les indices trop explicites.
  • Vérifier systématiquement les cases Correct ? avant enregistrement.
  • Utiliser le réordonnancement pour construire une progression pédagogique.

Dépannage rapide

  • Si vous êtes redirigé vers la connexion: la session admin a expiré.
  • Si une action échoue: vérifier la connectivité serveur puis réessayer.
  • Si une question n'apparaît pas: recharger la page pour forcer la synchronisation.
